# Infrastructure

Sprint 0 prepares local development and CI only. Production infrastructure will
be selected after Phase 3 architecture review.

Recommended services:

- Clerk for authentication.
- Stripe for cash adjustments.
- Cloudflare R2 for images.
- OneSignal for push notifications.
- PostHog for analytics.
- Sentry for monitoring.
- OpenAI API for AI-assisted listing and recommendations.
